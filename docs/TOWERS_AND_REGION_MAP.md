# Physical towers and Zhob–Sambaza map (v0.3.0)

Add tower creates one physical station. Select it, then Add radio for each Rocket M5 (up to four). Each radio keeps its own IP, ping history and alarms. Existing devices can be assigned using Edit → Physical tower. Left/Right chooses the drawing side; every Rocket radio can transmit and receive, so these are not transmitter-only/receiver-only settings. Tower shows observed online count. Dishes show their own status. Click tower, choose a radio, then Ping, History or Edit. Assign Parent / previous hop on the receiving-side radio to draw links between towers. Multiple radio links may overlap. No signal/CCQ/throughput telemetry is claimed.

Drag tower to save its position. Tower dialog also accepts latitude/longitude. Markers without GPS use manual positions. GPS outside this region is rejected in the dialog; an imported map can cover another area. Remove selected tower retains its radios as standalone devices and preserves history. No hardware is discovered or added automatically.

Map options → Download Zhob–Sambaza roads performs one small HTTPS Overpass vector request in the background. Road, river and place data are cached under the app data directory. No API key required. Download limits: 12 MB, approximately one minute; at most one manual request per minute. A failed request leaves existing map unchanged. Public Overpass is best-effort; personal occasional use only. Configure your own/provider HTTPS endpoint for wider deployments. No requests happen at startup, zoom or pan. Map download can delay shutdown until the bounded request finishes.

Export current map JSON lets another laptop Import saved map JSON with no Internet. Imports are validated and bounded. App renders vector roads, not satellite tiles. Standard OSM raster tile servers are not used for offline prefetch. Attribution is shown on the canvas: © OpenStreetMap contributors, ODbL 1.0, https://www.openstreetmap.org/copyright. Map data can be incomplete or outdated; GPS/markers are user configured, not discovered.

Default bounds: 31.25–31.90 north, 69.15–69.65 east. Anchors: Zhob 31.34082,69.44930 and Sambaza Fort 31.773901,69.349685. There are other localities called Sambaza; this release uses the fort/nearby village north of Zhob. A guide label is not a network device. Map background is a geographic grid if a vector download has not succeeded; UI states this explicitly. Starter region was downloaded during development and is validated during the Windows build, so the release includes roads offline.

v1 databases are backed up to monitor.sqlite3.pre-v030.bak before migration to schema v2. Devices, samples, settings and histories are retained. The previous app cannot read schema v2: use the v1 backup to roll back. Backups contain your configuration and IP addresses; keep them private.
